# RATi as a playable media service

RATi creates the content. Players choose actions. The product is a media service for entertainment.

The core loop is: pick a story, explore its sources, summon an avatar reaction, then return for the result. Stocks, sports, and memecoins are settings for these stories. Flash buys generated media actions. Show the exact cost before each action.

## This change

Avatar reactions use a single button. RATi supplies every word. Public comment requests accept an empty action payload. Public disclosure submission routes return a retired-route response. RATi manages editorial notices through its operator tools. Existing notices and corrections remain part of the story record.

Pulse introduces the media loop and links to Flash's existing scorecard. Reaction generation keeps its request key through retries and reloads. Each account has its own pending request. This protects a player's Flash balance when a reply is delayed.

## Next game features

Build a story collection with visible outcomes. Let players save stories, follow a character, and collect a completed chapter when its result arrives. Use fixed choices for every content action.

Award progress for exploration and completed story chapters. Keep progress separate from spending. A player should see what they completed, what changed since their last visit, and one clear next action.

Use a small set of words throughout the product: stories, avatars, chapters, reactions, and scorecards. Each label should describe the action or record behind it.

Measure the first story opened, the first avatar summoned, recovery after a delayed reply, and return visits to completed stories. Use observed results to choose the next game feature.
