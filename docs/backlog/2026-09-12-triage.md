## First implementation

This branch addresses #234 and #235. Saved coin quotes carry `current` or
`paused` through the public presenter. Paused prices show **Price paused** in a
neutral tone; Detail retains the saved observation time. Active quotes show
their saved 24-hour move. List and Map retain saved rows under the existing
board rule. Each refresh applies the same presenter.

Sports headlines use the existing `score_available` rule. Pregame rows show
the scheduled time. Started games show **Score pending** until confirmed
scores arrive, including when the saved pregame values are zero. Confirmed
zero scores remain valid. Detail's team scores use the same availability rule.

Checks exercise actual routes with controlled saved data, including upcoming,
delayed, live, confirmed zero and final sports states, paused/current coin
transitions, and exclusion of internal fields. Browser checks cover both
markets, all three screens, two refresh cycles and phone/desktop widths.
